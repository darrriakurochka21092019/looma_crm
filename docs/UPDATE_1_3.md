# Обновление LOOMA.CRM до 1.3.0 на Windows

В этой версии добавлены обучение при первом входе, подсветка блоков, кнопка пропуска и справка с частыми вопросами. Подсказки учитывают роль сотрудника и доступны повторно через знак **?** в верхней панели. Подробности — в [HELP.md](HELP.md).

1. Найдите чёрное окно, в котором работает CRM. Нажмите **Ctrl+C**. Если появится вопрос о завершении, введите **Y** и нажмите **Enter**.
2. Сохраните старую папку `LOOMA.CRM` целиком. Сделайте резервную копию базы в pgAdmin: правая кнопка по вашей рабочей базе → **Backup… / Резервная копия…** → выберите место для файла → **Backup**. Копия папки приложения сама по себе не содержит базу PostgreSQL.
3. Скачайте **новый** `LOOMA_CRM_READY.zip`. Распакуйте его целиком в новую папку, например `LOOMA_UPDATE_1_3_0` на рабочем столе. Внутри откройте папку `LOOMA.CRM`. Там должны быть `start-ready.bat`, папки `scripts`, `dist` и `dist-web`.
4. Откройте прежнюю рабочую папку. Скопируйте из неё **файл `.env` и папку `storage`**, если она есть, в новую папку `LOOMA.CRM`, рядом с новым `start-ready.bat`. Если Windows скрывает `.env`, включите в Проводнике **Вид → Скрытые элементы**. Не переносите старую папку `node_modules`.
5. Подключение к рабочей базе и публичный адрес в скопированном `.env` оставьте прежними. PostgreSQL должен работать. Дважды нажмите **новый `start-ready.bat`**. При первом запуске установятся зависимости, а новое поле для прогресса обучения добавится в базу автоматически.
6. Дождитесь строки **`Server listening`**, оставьте это окно открытым. Откройте CRM по прежнему адресу и нажмите **Ctrl+F5**. Внизу левого меню должна появиться версия **v1.3.0**. Войдите с прежним логином и паролем.
7. Появится окно знакомства с CRM. Нажмите **«Начать обучение»** или **«Пропустить обучение»**. Повторное обучение и ответы на вопросы всегда доступны через **?** сверху. Сотрудникам также нужно обновить свою страницу через **Ctrl+F5**.

Существующие заказы, оплаты, сотрудники, документы и настройки остаются в прежней базе. Новую базу создавать и демонстрационные данные добавлять не нужно. Одновременно запускайте один сервер CRM; старую папку оставьте как копию.

Если используете CloudPub, оставьте направление на **127.0.0.1, порт 3001** и прежнюю публикацию. Для доступа сотрудников должны работать компьютер, PostgreSQL, сервер CRM и CloudPub. Само скачивание архива сайт не обновляет: нужно запустить новую сборку по шагам выше.
