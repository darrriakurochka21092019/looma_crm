LOOMA.CRM — первая рабочая версия

Сначала распакуйте архив целиком в отдельную папку.

Вариант 1. С Docker Desktop
Установите Node.js 24 и запустите Docker Desktop.
Откройте start.bat. Он создаст настройки, соберёт приложение и создаст владельца.
После завершения откроется http://localhost:3001.

Логин владельца: owner@looma.local
Пароль сгенерирован автоматически и записан в файл .env, строка SEED_PASSWORD.
Файл .env появится при первом запуске. Откройте его через Блокнот.
Не публикуйте .env и не передавайте его сотрудникам.

Вариант 2. Без Docker
Установите Node.js 24 и PostgreSQL 17, создайте базу и укажите её пароль в DATABASE_URL.
Пошаговая инструкция находится в README.md, раздел «Запуск без Docker».
Для дальнейших запусков предусмотрен start-local.bat.

Внутри CRM есть клиенты, заказы, производство, финансы, задачи, документы,
отчёты, приглашения сотрудников и импорт Excel. Демонстрационные заказы
добавляются отдельно; обычный запуск не заполняет рабочую базу примерами.

Перед реальными заказами проверьте сценарии на своём PostgreSQL и восстановление копии.
Подробности выполненных проверок и ограничения — docs/ACCEPTANCE.md.
Короткая инструкция сотрудникам — docs/QUICK_GUIDE.md.
